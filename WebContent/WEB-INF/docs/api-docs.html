Mini Digital Wallet – API Endpoints

Authentication

  • POST /LoginServlet
    Params: username/email, password
  • POST /RegisterServlet
    Params: username, email, password
  • GET /LogoutServlet

Wallet Operations

  • POST /AddFundsServlet
    Params: amount
  • POST /TransferServlet
    Params: recipient (email or username), amount
  • GET /DashboardServlet
    Displays current balance
  • GET pages/history.jsp
    Shows transaction history

Responses

All servlets redirect or forward to appropriate JSPs. Simulated emails are logged to the console.
